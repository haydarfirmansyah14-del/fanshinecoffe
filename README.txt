FANSHINE WEBSITE — CARA PAKAI

Isi folder:
- index.html
- assets/logo-fanshine.png
- assets/logo-kelas.png
- assets/poster-fanshine.jpg

Poster disimpan sesuai gambar asli, tanpa crop/ubah rasio. Di website width menyesuaikan layar dan height otomatis (height:auto).

TES DI HP:
1. Buka folder project dan buka index.html di browser untuk pratinjau jika editor/file manager mendukung.
2. Tes pilihan Regular/Jumbo, tombol jumlah, total harga, dan form.
3. Pastikan tombol WhatsApp membuka nomor penjual 6282137859755.

PUBLIKASI VIA GITHUB PAGES:
1. Login GitHub dan buat repository baru bernama fanshinecoffe (atau nama lain yang tersedia).
2. Upload index.html serta folder assets beserta tiga file di dalamnya; jangan ubah struktur folder.
3. Buka Settings > Pages.
4. Pada Build and deployment pilih Deploy from a branch, pilih branch main dan folder /(root), lalu Save.
5. Tunggu proses publish selesai. URL biasanya https://USERNAME.github.io/NAMA-REPOSITORY/ .
Catatan: URL fanshinecoffe.github.io hanya cocok jika username GitHub-mu memang fanshinecoffe dan repository Pages dibuat dengan aturan GitHub Pages yang sesuai.
